== 0.1.0 (21 avril 2026)

=== Ajouté

* `I18n.load(path, locale)` : charge un fichier YAML plat dans une locale.
  Les appels successifs fusionnent, une clé dupliquée écrase la précédente.
* `I18n.t(key, **params)` : traduit avec interpolation `%{name}`, fallback
  sur `:en` si la locale active n'a pas la clé, `KeyError` si même `:en`
  manque.
* Détection de la locale via `LC_ALL` / `LC_MESSAGES` / `LANG` (deux
  premières lettres) ; override manuel via `I18n.locale = :xx`.
* `I18n.reset` pour vider la table (utile en tests).
* Extraction du moteur i18n initialement embarqué dans beryl
  (module `Beryl::I18n`) après retour d'expérience : « toujours des
  petits fichiers maintenables que des gros fichiers obèses ».
* CI GitHub Actions : format + specs Linux et FreeBSD 15.
